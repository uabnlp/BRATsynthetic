# Commits
* Do not commit any code unless a human approves
* After doing your work, write a file AGENT_proposed_commit.txt where AGENT is Claude Code|Codex|Qwen3 etc...
## Commits developed by AI and reviewed by humans
Commits that are developed jointly by AI and humans should be in the following format below. The name of the AI can be replaced by the appropriate AGENT name, likewise with the HUMAN author obtained via git config user.name
Example Signing below:
Authored-By: [Claude Code](https://claude.ai/code)
Edited/Reviewed-By: John Osborne <ozborn@uab.edu>
